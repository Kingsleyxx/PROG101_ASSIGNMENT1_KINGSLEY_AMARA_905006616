# PROG101_ASSIGNMENT1_KINGSLEY_AMARA_905006616
This is a project that solves waste disposal and help keeps the community clean

## Project Background
The problem affects several groups of people, including:
> Residents and households who live in affected communities.
> Children who play around their surroundings.

## How The System Works
1.	Start the system.
2.	Enter the resident’s name.
3.	Enter the waste location.
4.	Select the type of waste.
5.	Describe the waste problem.
6.	Check if all information is complete.
7.	If information is missing, request it again.
8.	If complete, save the report.
9.	Generate a report ID.
10.	Notify the waste management officer.
11.	Assign a collection team.
12.	Update the status to In Progstatus13. Collect the waste.
13.	Update the status to CompletedIn14. Display a confirmation message.
14.	End the system.
